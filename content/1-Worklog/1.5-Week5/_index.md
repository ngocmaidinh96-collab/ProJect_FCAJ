### Week 5 Achievements:

* Understand Amazon S3 and its role in object storage.

* Become familiar with the basic S3 components:
  * Bucket
  * Object
  * Object Key
  * Bucket Policy

* Practice storing product images in Amazon S3:
  * Create an S3 bucket.
  * Upload images to the bucket.
  * Manage stored objects.
  * Integrate image URLs into the PHP website.

* Learn about S3 data protection mechanisms:
  * S3 Versioning.
  * S3 Cross-Region Replication.
  * IAM Policy.
  * S3 Bucket Policy.

* Understand how to control access permissions for images and data stored in S3.

* Learn how to restore previous object versions when data is overwritten or accidentally deleted.

* Understand the role of S3 in data storage and supporting Disaster Recovery strategies.
