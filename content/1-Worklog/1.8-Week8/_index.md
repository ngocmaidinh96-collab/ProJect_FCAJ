* Practice restoring AWS resources from backups.
* Verify data integrity after restoration.
* Evaluate the website's recovery capabilities.

### Week 8 Achievements:

* Understand the process of restoring AWS resources from backups.

* Practice or study the application server recovery process:
  * Amazon EC2.
  * Amazon EBS.
  * AWS Backup Recovery Point.
  * Verify network configuration after restoration.

* Practice database recovery:
  * Amazon RDS Snapshot.
  * AWS Backup Recovery Point.
  * Check the database status after restoration.
  * Verify the connection between the PHP application and RDS.

* Learn how to restore product image data:
  * Amazon S3 Versioning.
  * Restore a previous object version.
  * Verify image paths after restoration.

* Verify website functionality after the recovery process:
  * Access the website.
  * Display the product list.
  * Check database connectivity.
  * Verify that images can be loaded from S3.

* Use AWS Management Console and system logs to identify errors.

* Document additional configuration steps required to return the website to an operational state.
