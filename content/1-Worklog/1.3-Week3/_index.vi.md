### Kết quả đạt được tuần 3:

* Hiểu cách triển khai ứng dụng web trên Amazon EC2 sử dụng Amazon Linux.

* Cài đặt và cấu hình môi trường máy chủ web:
  * Linux
  * Apache HTTP Server
  * PHP

* Tìm hiểu các thao tác quản trị Linux:
  * Quản lý tệp và thư mục.
  * Phân quyền truy cập.
  * Kiểm tra trạng thái dịch vụ.
  * Đọc log và xử lý lỗi cơ bản.

* Xây dựng và triển khai website bán hàng bằng PHP:
  * Tạo giao diện website.
  * Hiển thị danh sách sản phẩm.
  * Xây dựng các trang chức năng cơ bản.

* Cấu hình Security Group để cho phép các kết nối cần thiết:
  * SSH để quản trị máy chủ.
  * HTTP để truy cập website.
  * HTTPS khi triển khai chứng chỉ SSL/TLS.

* Kiểm tra khả năng truy cập website thông qua trình duyệt.

* Hiểu vai trò của EC2, Apache và PHP trong kiến trúc ứng dụng web.
