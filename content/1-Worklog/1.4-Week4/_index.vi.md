### Kết quả đạt được tuần 4:

* Hiểu vai trò của Amazon RDS trong việc quản lý cơ sở dữ liệu trên AWS.

* Tìm hiểu các thành phần và chức năng của cơ sở dữ liệu:
  * Amazon RDS for MySQL
  * DB Instance
  * Database
  * Table
  * SQL Query

* Thực hành quản lý dữ liệu bằng MySQL:
  * Tạo database.
  * Tạo bảng products.
  * Thêm và truy vấn dữ liệu sản phẩm.
  * Kiểm tra dữ liệu trong cơ sở dữ liệu.

* Kết nối website PHP trên EC2 với Amazon RDS:
  * Cấu hình thông tin kết nối database.
  * Thiết lập tài khoản truy cập MySQL.
  * Kiểm tra kết nối giữa ứng dụng và cơ sở dữ liệu.

* Cấu hình Security Group để kiểm soát kết nối đến RDS.

* Tìm hiểu các cơ chế bảo vệ dữ liệu của RDS:
  * Automated Backups.
  * DB Snapshots.
  * Point-in-Time Recovery.

* Hiểu cách kết hợp EC2 và RDS để triển khai ứng dụng web có cơ sở dữ liệu tập trung.
