### Kết quả đạt được tuần 1:

* Hiểu AWS là gì và nắm được các nhóm dịch vụ cơ bản:
  * Compute
  * Storage
  * Networking
  * Database
  * Security

* Làm quen với AWS Management Console và AWS CLI.

* Tìm hiểu IAM và các thành phần quản lý quyền truy cập:
  * IAM User
  * IAM Role
  * IAM Policy

* Tìm hiểu các dịch vụ và thành phần cơ bản:
  * Amazon EC2
  * Amazon EBS
  * Amazon Machine Image (AMI)
  * Key Pair
  * Elastic IP

* Tìm hiểu cách sử dụng AWS CLI để:
  * Kiểm tra thông tin cấu hình.
  * Liệt kê các AWS Region.
  * Kiểm tra thông tin EC2.
  * Quản lý Key Pair và tài nguyên AWS.

* Xác định được các dịch vụ cần thiết để xây dựng hệ thống Backup và Disaster Recovery.
