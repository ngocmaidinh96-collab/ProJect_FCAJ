### Kết quả đạt được tuần 2:

* Hiểu kiến trúc mạng trên AWS và vai trò của Amazon VPC.

* Nắm được các thành phần mạng cơ bản:
  * VPC
  * Public Subnet
  * Private Subnet
  * Route Table
  * Internet Gateway

* Hiểu cách kiểm soát lưu lượng mạng bằng:
  * Security Group
  * Network ACL

* Triển khai và cấu hình Amazon EC2:
  * Lựa chọn AMI và Instance Type.
  * Tạo Key Pair.
  * Kết nối SSH đến máy chủ.
  * Kiểm tra trạng thái EC2.

* Tìm hiểu Amazon EBS để lưu trữ dữ liệu cho máy chủ EC2.

* Tìm hiểu Elastic IP và cách sử dụng địa chỉ IPv4 công khai.

* Hiểu cách kết hợp VPC, EC2 và Security Group để xây dựng hạ tầng cho website.
