* Understand the network architecture on AWS.

### Week 2 Achievements:

* Understand the network architecture on AWS and the role of Amazon VPC.

* Become familiar with the basic networking components:
  * VPC
  * Public Subnet
  * Private Subnet
  * Route Table
  * Internet Gateway

* Understand how to control network traffic using:
  * Security Groups
  * Network ACLs

* Deploy and configure Amazon EC2:
  * Select an AMI and Instance Type.
  * Create a Key Pair.
  * Connect to the server via SSH.
  * Check the EC2 instance status.

* Learn about Amazon EBS for storing data on EC2 instances.

* Learn about Elastic IP and how to use public IPv4 addresses.

* Understand how to combine VPC, EC2, and Security Groups to build the infrastructure for a website.
